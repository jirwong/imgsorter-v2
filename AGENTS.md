# AGENTS.md

This file provides guidance to AI coding agents when working with code in this repository.

## Quick Commands

### Build & Development

- **`pnpm build`** - Compile TypeScript to JavaScript with esbuild (outputs to `dist/`)
- **`pnpm dev`** - Run the TypeScript entry point with tsx
- **`pnpm dev:watch`** - Watch `src/` and rebuild/rerun on changes via tsx watch

### Type Checking & Linting

- **`pnpm typecheck`** - Type-check without emitting code (`tsc --noEmit`)
- **`pnpm lint`** - Run oxlint on `src/`
- **`pnpm lint:fix`** - Run oxlint with auto-fix

### Testing

- **`pnpm test`** - Run tests once with Vitest
- **`pnpm test:watch`** - Run tests in watch mode

### Formatting

- **`pnpm format`** - Format all code with Prettier
- **`pnpm format:check`** - Check formatting without making changes

## Conventions

### TypeScript

- Strict mode is enabled — all code must have proper type annotations
- Use `ES2023` and `NodeNext` module resolution
- Source files go in `src/` with `.ts` extension
- Use named exports, not default exports
- Unused variables prefixed with `_` are allowed (e.g., `_unusedParam`)

### Code Style (Prettier)

- 2-space indentation, no tabs
- Single quotes, semicolons required
- Print width: 120 characters
- Trailing commas: `all`
- Arrow parens: always

### Testing

- Tests are colocated with source files (`*.test.ts`)
- Use Vitest's `describe`/`it`/`expect` pattern
- Import test helpers from `vitest`: `import { describe, it, expect } from 'vitest'`
- Coverage thresholds (80%) are enforced by `pnpm test:coverage`

### Git

- **Pre-commit hook:** lint-staged runs oxlint + Prettier on staged TS files
- **Pre-push hook:** typecheck + lint
- Commits should follow [Conventional Commits](https://www.conventionalcommits.org/)
- Keep commits focused — one logical change per commit
- Imperative mood, 50-char subject line max

### Configuration

- User configuration is a YAML file (`config.yaml`) validated with a zod schema in `src/utilities/load-config.ts`
- There are no environment variables; the template's `src/env.ts` was removed during migration

## Workflow

1. Make changes in `src/`
2. Run `pnpm typecheck` to verify types
3. Run `pnpm lint` to check for issues
4. Run `pnpm test` to run tests
5. Run `pnpm format` before committing
6. Commit — pre-commit hook will auto-format staged files
